# 网页译读

独立实现的 Chromium / Firefox 翻译扩展，包含网页、选区、指向翻译、术语表、输入与写作辅助、字幕、文档、图片工具和原生侧栏。默认由用户主动发送；逐站自动翻译须单独启用并授权。所有请求使用用户配置的 OpenAI 兼容 Chat Completions 服务，没有内置服务、默认模型、账户、遥测或云同步。

## 安装

先使用 PATH 中的 Node.js 与 pnpm：

```powershell
pnpm install
pnpm test
pnpm typecheck
pnpm build
```

设置页为随扩展打包的 React + MUI 本地静态页面，无需启动应用服务器。

### Chromium / Edge

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启开发者模式，选择“加载解压缩的扩展”。
3. 选择本项目的 [Chromium 产物目录](<dist/chromium/>)。
4. 固定工具栏图标，打开设置配置服务。

### Firefox

1. 打开 `about:debugging#/runtime/this-firefox`。
2. 选择“临时载入附加组件”，打开 [Firefox manifest](<dist/firefox/manifest.json>)。
3. 接受所声明的网页文本及服务认证信息传输范围，然后配置服务。

临时扩展在 Firefox 退出后卸载；此产物未签名、未发布，不能当作已签名的商店安装包。Firefox 使用非持久后台页面，Chromium 使用 service worker。

## 配置与使用

1. 在设置中填写 **API 前缀地址**与**模型标识**，按服务要求填写可选密钥。前缀后自动追加 `/chat/completions`，例如本机服务前缀 `http://127.0.0.1:8000/v1`。
2. 点击“保存设置”：仅保存本机配置，不发送文本。
3. 点击“授权主机权限”：浏览器单独询问是否允许访问所选服务主机，不进行连接测试。
4. 点击“测试服务连接”：向已保存并已授权的服务发送固定文本 `Hello.`。此操作可能计费。
5. 打开普通网页，通过扩展工具栏选择“开始翻译”。双语与仅译文之间切换复用当前成功结果。
6. 暂停保留已有译文；继续处理未完成和新内容；“重试失败”只重试失败片段；还原撤销扩展显示，不回退网站状态。
7. 选中网页文字后使用右键菜单或工具栏选区按钮。结果在扩展本地页面显示，点击复制才写入剪贴板。
8. 在工具栏启用“指向翻译”，用 **Alt + 鼠标左键**点击普通文字，在浮层查看结果。移动鼠标、普通点击和网页合成点击不发送内容；关闭浮层或按 Esc 取消当前操作。指向模式与整页翻译互斥，链接、按钮及编辑区域不参与指向翻译。
9. 在设置页维护本地术语表。仅当前文本中匹配、目标语言一致的术语会随翻译发送；模型可能不完全遵从。支持预览后原子导入 JSON，整批存在错误时不写入。清除服务保留词表，清除全部会删除词表。
10. 从工具栏打开“SRT 字幕翻译”，选择 UTF-8 文件并本地预览，确认接收方后才发送字幕正文。支持取消、只重试未完成条目、原文导出及全部完成后的译文导出；保留编号、顺序和时间轴。配置、术语或权限变化会使旧译文失效。

云端地址仅允许 HTTPS。HTTP 只接受明确的 `localhost` 或 `127.0.0.1`，不接受局域网或其他本机别名。地址不能带用户名、密码、查询或片段。浏览器主机授权不区分端口；实际请求仍使用你保存的完整地址。更换服务 origin 会清除旧密钥，新接收方需要重新填写密钥。

无密钥的本机服务也可使用。连接测试成功只表示这次接口返回了有效文本，无法保证翻译质量、后续额度或图片识别能力。

### 工作台、侧栏与其他工具

| 功能 | 使用方式与范围 |
|---|---|
| 文字与写作工作台 | 在本地输入文字，明确发送以翻译、润色、纠错或精简。结果支持本地编辑、恢复服务结果和主动复制；切换工具保留当前会话内容。 |
| 输入辅助 | 先聚焦源页面输入框，从工具栏捕获，预览翻译或改写结果后再次确认写回。支持普通文本输入和简单纯文本可编辑区域；密码、OTP、支付等明确安全字段及禁用字段不处理。用户改稿后拒绝覆盖恢复；复杂富文本限预览和复制，不自动提交表单。 |
| 原生侧栏 | Chromium 使用 `sidePanel`，Firefox 使用 `sidebarAction`，复用工作台。提供当前授权网页的翻译、暂停、还原和状态；未授权的新标签页须先点击工具栏授予访问，不隐式扩大权限。 |
| TXT / HTML 文档 | 本地选择严格 UTF-8 的 TXT、HTML、HTM，最多 1 MiB。HTML 仅保留安全阅读结构，去除脚本、表单、属性和外部资源。确认后每轮最多发送 100 段，可继续、取消或只重试失败段；导出 TXT 或安全 HTML 的双语/仅译文阅读版，未译部分明确保留原文。 |
| 逐站自动翻译 | 从当前站点工具栏明确同意长期发送并申请主机权限，保存目标语言及模式。在设置中停用或删除规则。规则严格匹配协议、主机和端口；浏览器主机权限自身覆盖同协议同主机的所有端口。仅可见活动标签页启动，同文档 SPA 导航共用 100 次预算；暂停/还原后不会因同文档导航自启。 |
| 视频文字轨 | 列出当前页可合法读取的 `video.textTracks`，选择视频与轨道并同意本次播放发送后，翻译当前字幕。支持双语/仅译文、跳转、关闭及预算用尽后主动继续。不抓取私有播放器接口，不识别音频，不绕过 DRM。 |
| 图片文字 | 工作台选择 PNG/JPEG/WebP，在本地预览或裁剪，确认后将实际预览区域发给所选模型。需要兼容端点的视觉能力；未验证、空识别、格式错误或服务拒绝均明确反馈，不切换服务。图像路径不发送完整术语表。 |
| 区域截图 | 工具栏主动框选当前可见网页。浏览器可能先在本地取得整个可见页，扩展仅将裁剪区交给工作台；再次确认才上传。此 Windows 环境的真实截图验收因 OS 前台焦点丢失而被安全取消，端到端像素检查仍未通过。 |
| 译文编辑与学习 | 网页翻译完成后打开本地审查面板，编辑译文、恢复服务译文或逐段遮蔽/揭示。操作不产生翻译请求；原文变更、重译或还原后旧编辑失效，不持久保存。 |

术语导入格式如下，最多 200 项；同目标语言的原词不能重复，导入时先校验整批并预览数量，再确认写入：

```json
{"version":1,"entries":[{"source":"example","target":"示例","targetLanguage":"zh-CN"}]}
```

原词最多 80、译词最多 160 个 Unicode 码点；匹配区分大小写，重叠时最长原词优先。每请求最多附带 20 个匹配项、原词与译词合计最多 2000 码点，超限会明确停止该请求。术语适用于文字翻译流程，连接测试与保留原语言的写作操作不附带术语。

## 数据、权限与限制

- 在主动操作或已明确同意的站点/字幕会话范围内发送所需内容、语言参数和相关术语；不附带网页 URL、标题、Cookie、文件名、时间轴或浏览历史。图片仅在确认实际预览区域后发送。
- 整页翻译默认跳过脚本、样式、隐藏文字、表单字段和可编辑草稿；输入辅助只处理用户明确捕获的目标。选中文字、草稿或图片仍可能含个人信息，不保证自动识别敏感内容，请确认接收方与费用。
- 密钥保存在扩展 origin 的 IndexedDB，不进内容脚本、浏览器同步或日志。本机存储不是加密保险箱，无法抵御本机恶意软件。
- 除用户主动导出的文件外，原文、译文、图像与任务只在当前会话内存保留。偏好、术语及明确建立的站点规则保存在本机。清除服务删除凭据并禁用自动规则；重新配置同一服务也不会自行重新启用。清除全部还删除术语与规则。清除本机数据不能撤回服务端已收到的数据。
- `activeTab` / `scripting` 用于主动访问当前顶层网页；服务与自动站点主机按需申请。`webNavigation` 用于导航失效及已同意站点的调度，不保存浏览历史。Chromium `sidePanel` 仅提供原生侧栏；剪贴板权限只用于主动复制，不读取剪贴板。
- 单片最多 2000 个 Unicode 字符；长文本节点完整分片。每次主动网页操作最多 100 次请求，达到上限需点击继续。并发上限 2，远程请求超时 25 秒，无自动重试。选区超过 2000 字符请缩小范围。
- 不覆盖浏览器系统页、受限商店页面、iframe、Shadow DOM 或已卸载的虚拟列表历史内容。
- SRT 仅支持严格 UTF-8（可带 BOM），文件最多 1 MiB、2000 条字幕、正文总计 400000 码点，单条源文最多 2000 码点；累计译文最多 4 MiB。选择文件不联网，发送前显示实际条数；文件名与时间轴不发给服务。
- 网站文字更新会使旧译文失效；还原保留原节点、网站新内容、事件和输入。暂停、还原或导航后迟到结果不会写入页面；已经发送的远程请求可能已被处理或计费。
- 未启用自动规则的页面在刷新、SPA 导航或后台中断后需主动重新启动。后台重启不会重传已打开网页；自动规则仅在新的有效导航中按同意范围运行。关闭普通工具栏面板不暂停网页会话；关闭工作台或侧栏会取消它持有的任务。
- 图像只支持 PNG/JPEG/WebP，编码最多 4 MiB、最多 1600 万像素；实际上传的 PNG 裁剪结果也受 4 MiB 限制。文本连接测试不能证明模型支持视觉。
- 不包含账户/云同步、PDF/DOCX/EPUB 解析、无字幕语音识别或 DRM/私有播放器适配。云同步缺少后端、账号授权及数据删除合同；其他复杂格式和本地 OCR 缺少解析库/模型，未自行安装或下载。

- [共享模块](<src/shared/>)：消息合同、服务地址及文件/图像规则。
- [后台](<src/background/>)：平台入口、权限、配置、服务请求和任务生命周期。

- [本地 UI](<src/ui/>)、[文档解析](<src/documents/>)、[行为测试](<tests/>)。

浏览器脚本都使用已安装的 Playwright 配套 Chromium、全新隔离 profile 和本地受控服务；不会读取用户浏览器配置或自动下载浏览器。主机授权通过该测试窗口的 Windows UI Automation 确认。

| 命令 | 验证内容 |
|---|---|

| `node scripts/subtitles-browser-test.mjs` | SRT 选择、分页、取消、重试、下载及结果失效 |
| `node scripts/workbench-browser-test.mjs` | 工作台、写作、输入确认写回、文档下载、原生侧栏 |

| `node scripts/review-browser-test.mjs` | 本地编辑、恢复、学习显示及网站状态保持 |
| `node scripts/images-browser-test.mjs` | 图片文件、实际区域截图/裁剪/上传像素；区域失败时返回失败，不用独立文件路径的成功掩盖 |

`node scripts/firefox-check.mjs` 使用 Playwright Firefox 与内置 BiDi。新增功能当前只保证 Firefox 构建，运行时验收暂缓。

先显式安装配套浏览器，再运行验证：

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = Join-Path $env:LOCALAPPDATA 'ms-playwright'
$env:PLAYWRIGHT_SKIP_BROWSER_GC = '1'
node node_modules/playwright-core/cli.js install chromium firefox
node scripts/browser-test.mjs
node scripts/firefox-check.mjs
```

浏览器下载保存到 Playwright 标准用户缓存。验证使用新建空白 profile，不读取用户浏览器状态，不修改 ACL 或关闭浏览器沙箱。受控服务只监听本机，返回确定性文本或图像协议测试结果；它不具备真实翻译或 OCR 能力。
