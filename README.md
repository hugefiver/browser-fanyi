# 网页译读

「网页译读」是一个面向 Chromium / Firefox 的浏览器翻译扩展。所有翻译请求都发送到你自行配置的 OpenAI 兼容服务，没有内置服务、账户、遥测或云同步；翻译永远由你主动发起，逐站自动翻译需要单独授权。

## 功能一览

| 功能 | 说明 |
|---|---|
| 网页翻译 | 整页双语/仅译文，支持暂停、继续、重试失败片段、一键还原 |
| 选区翻译 | 选中网页文字后从右键菜单或工具栏翻译 |
| 指向翻译 | Alt + 点击页面文字，浮层显示结果 |
| 术语表 | 本地维护术语对照，翻译时自动附带 |
| SRT 字幕翻译 | 本地选择字幕文件翻译并导出 |
| 视频字幕翻译 | 翻译当前网页视频的可读字幕轨 |
| 工作台 | 翻译、润色、纠错、精简文字；文档、图片与截图工具入口 |
| 输入辅助 | 把翻译/改写结果确认后写回页面输入框 |
| 文档翻译 | TXT / HTML 文件翻译并导出阅读版 |
| 图片文字 | 图片文字识别与翻译（需模型支持视觉） |
| 区域截图 | 框选网页区域后交给工作台识别翻译 |
| 逐站自动翻译 | 对明确同意的网站自动翻译 |
| 译文编辑与学习 | 本地编辑译文、逐段遮蔽/揭示辅助记忆 |
| 原生侧栏 | 浏览器侧栏中复用工作台 |

## 安装

从 [Releases 页面](../../releases) 下载对应浏览器的 zip 并解压，然后按浏览器加载：

**Chromium / Edge**

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启右上角「开发者模式」，选择「加载解压缩的扩展」。
3. 选择解压后的 Chromium 目录。
4. 固定工具栏图标，打开设置页配置服务。

**Firefox**

1. 打开 `about:debugging#/runtime/this-firefox`。
2. 选择「临时载入附加组件」，打开解压后目录中的 `manifest.json`。
3. 接受所声明的权限后配置服务。

> Firefox 的临时载入在浏览器退出后卸载；此扩展未在商店签名发布。开发者也可以从源码构建，见下文「从源码构建」。

## 配置翻译服务

1. 打开扩展设置页，填写 **API 前缀地址** 与 **模型标识**，按服务要求填写可选密钥。前缀后自动追加 `/chat/completions`，例如本机服务前缀 `http://127.0.0.1:8000/v1`。
2. 点击「保存设置」。配置只保存在本机。
3. 点击「授权主机权限」，浏览器会单独询问是否允许访问所选服务主机。
4. 点击「测试服务连接」确认可用。此操作会向你的服务发送固定文本 `Hello.`，可能计费。

服务地址要求：

- 云端地址仅允许 HTTPS；HTTP 只接受 `localhost` 或 `127.0.0.1`。
- 地址不能带用户名、密码、查询或片段。
- 更换服务地址会清除旧密钥，需要重新填写。
- 无密钥的本机服务也可以使用。

## 日常使用

### 网页翻译

打开普通网页，点击工具栏图标选择「开始翻译」。可在双语与仅译文之间切换（复用当前结果）；「暂停」保留已有译文，「继续」处理未完成和新内容，「重试失败」只重试失败片段，「还原」撤销扩展显示、不回退网站本身。

### 选区与指向翻译

- 选中网页文字后使用右键菜单或工具栏选区按钮，结果在扩展本地页面显示，点击复制才写入剪贴板。
- 在工具栏启用「指向翻译」后，用 **Alt + 鼠标左键** 点击普通文字查看浮层结果；关闭浮层或按 Esc 取消。链接、按钮和编辑区域不参与指向翻译，指向模式与整页翻译互斥。

### 术语表

在设置页维护本地术语表：仅当前文本中匹配且目标语言一致的术语会随翻译发送（模型可能不完全遵从）。支持先预览再导入 JSON，整批有错时不写入：

```json
{"version":1,"entries":[{"source":"example","target":"示例","targetLanguage":"zh-CN"}]}
```

### 字幕

- **SRT 字幕翻译**：从工具栏打开，选择 UTF-8 字幕文件本地预览，确认后才发送字幕正文。支持取消、只重试未完成条目、原文导出和译文导出，保留编号、顺序和时间轴。
- **视频字幕翻译**：在视频页面选择视频与字幕轨并同意本次发送后，随播放翻译当前字幕，支持双语、跳转和关闭。不抓取私有播放器接口、不识别音频、不绕过 DRM。

### 工作台与工具

从工具栏打开工作台，包含：

- **文字与写作**：输入文字后明确发送，可翻译、润色、纠错或精简，结果可编辑、恢复和复制。
- **输入辅助**：先聚焦源页面输入框，从工具栏捕获，预览结果后确认写回。密码、验证码、支付等安全字段不会处理；不会自动提交表单。
- **文档翻译**：选择 TXT / HTML 文件（严格 UTF-8，最大 1 MiB），确认后分段翻译，可导出双语或仅译文的阅读版。
- **图片文字**：选择 PNG/JPEG/WebP 图片，本地预览或裁剪，确认后发送实际预览区域。需要模型支持视觉能力。
- **区域截图**：框选当前网页可见区域，裁剪结果交给工作台，再次确认才上传。
- **原生侧栏**：Chromium 与 Firefox 的浏览器侧栏复用工作台，可控制当前网页的翻译。

### 逐站自动翻译

在常用站点上，从工具栏明确同意后可长期自动翻译并保存目标语言与模式；随时可在设置中停用或删除规则。只有你同意过的站点会自动翻译，且只在可见的活动标签页启动。

### 译文编辑与学习

网页翻译完成后可打开本地审查面板：编辑译文、恢复服务译文，或逐段遮蔽/揭示以辅助学习。这些操作不产生翻译请求，编辑不持久保存。

## 数据与隐私

- 只有你主动发送或明确同意的内容会发给你的翻译服务；不附带网页 URL、标题、Cookie、文件名或浏览历史。
- 密钥保存在本机，不进入内容脚本、浏览器同步或日志。
- 原文、译文、图片和任务只在当前会话内存中保留；主动导出的文件除外。
- 清除服务会删除密钥并停用自动规则；清除全部还会删除术语与规则。清除本机数据不能撤回服务端已收到的数据。
- 权限按需申请：访问当前网页需要你主动操作，访问服务主机需要单独授权。

## 使用限制

- 单次发送的文本片段最多 2000 字符；每次网页翻译最多 100 次请求，达到上限后点击继续。
- 远程请求超时 25 秒，无自动重试。
- 整页翻译不处理浏览器系统页、商店页、iframe 和 Shadow DOM 内容。
- SRT 文件最大 1 MiB、最多 2000 条；图片最大 4 MiB、1600 万像素。
- 连接测试成功不代表翻译质量或图片识别能力；图片识别取决于所选模型是否支持视觉。
- 翻译质量、服务额度与费用由你配置的服务决定。

## 从源码构建

```powershell
pnpm install
pnpm build
```

构建产物在 `dist/chromium/` 与 `dist/firefox/`。运行完整测试请使用 `pnpm test`。
